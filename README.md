# 个人工作自动化 Web 应用（演示版）

> 这是一个个人工作自动化平台的**核心代码演示包**，用于技术演示与交流。
> 本仓库为**脱敏版本**：不含任何真实业务数据、真实邮箱、真实姓名或内部系统地址。

## 这是什么

一套面向工厂/车间日常工作的自动化工作台，后端为 Python FastAPI，前端为单文件 HTML + 原生 JS。主要解决报表处理、邮件通知、计划任务、SAP 事务自动化等重复性工作。

## 技术栈

- **后端**：Python 3.11 + FastAPI + pandas / openpyxl
- **前端**：原生 HTML / CSS / JavaScript（单文件应用），ECharts 图表、html2canvas 截图
- **数据处理**：Excel 读写、VLOOKUP、正则提取、参数扫描等模块化设计

## 目录结构

```
.
├── main.py                 # FastAPI 后端主程序（路由 / 业务编排）
├── index.html              # 前端单文件应用（约 1.9MB，全部页面与交互）
├── auto_tasks.js           # 自动化任务流水线（前端编排）
├── trigger.js              # 计划任务触发器
├── box_task.js             # 物料任务处理
├── apd22.js / bom_layering.js
│                           # 业务页面逻辑
├── echarts.min.js / html2canvas.min.js
│                           # 第三方前端库
└── _src/                   # 核心数据处理模块
    ├── 01_数据读写/        # Excel 读取 / 写入 / 伪 xls 转换
    ├── 02_数据处理/        # VLOOKUP / 正则提取 / 替换 / 拆列 / 参数扫描
    └── 04_基础设施/        # 日志与公共基础设施
```

## 核心模块一览

| 模块 | 功能 |
|------|------|
| 数据读写 | 兼容 .xlsx / .xlsm / .xls，自动识别表头行，SAP 文本报表（GBK+Tab）转真 xlsx |
| VLOOKUP | 左表/右表关联，键列自动识别，表头行可变 |
| 参数扫描 | 可配置分隔符的多参数提取，结果写回与下载 |
| 邮件编排 | HTML 风格报表表格、附件汇总、异常通知 |
| 计划任务 | 定时任务配置与触发（cron 风格） |
